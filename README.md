# harvesting-test-data
Test files for harvesting

# CBS 
**Original dataset**:  
<https://data.overheid.nl/dataset/299-overledenen--doodsoorzaak--kwartaal-en-jaar-overlijden>

The original metadata was **not compliant with Health-DCAT**.  
To make it compliant, we used the **[EHDS metadata editor](https://ehds.healthdataportal.eu/editor2/)** to enter the data.  

For all **mandatory fields** that were missing in the original metadata, we retrieved information from the **CBS website**, and in some cases made **educated guesses**.  

The metadata generated by the editor was validated against **version 4 of Health-DCAT** using the **ITB validator**, available here:  
<https://health-data-itb-rdf-validator.acceptance.data.health.europa.eu/shacl/ehds/upload>
